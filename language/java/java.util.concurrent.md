
- **실행기(Executors)**: `Executor`, `ExecutorService`, `ThreadPoolExecutor`, `ScheduledThreadPoolExecutor`
    
- **태스크/Future**: `Future`, `FutureTask`, `CompletableFuture`, `RunnableFuture`
    
- **Fork/Join**: `ForkJoinPool`, `ForkJoinTask`
    
- **동시 컬렉션**: `ConcurrentHashMap`, `ConcurrentLinkedQueue`, `CopyOnWriteArrayList`
    
- **락/동기화 도구**: `Lock`, `ReentrantLock`, `ReadWriteLock`, `Semaphore`, `CountDownLatch`, `CyclicBarrier`, `Phaser`
    
- **원자 변수**: `AtomicInteger`, `AtomicLong`, `AtomicReference`, `LongAdder` 등
    
- **저수준 유틸**: `LockSupport` (park/unpark)
