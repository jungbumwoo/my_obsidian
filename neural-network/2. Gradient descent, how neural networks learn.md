
## Cost Function
신경망 처음 만들면, weight, bias 값은 초기화되어있지 않다.
얼마나 틀렸는지 어떻게 측정? 

$$ C = \sum_i (a_i - y_i)^2 $$

- `a_i`: 신경망의 실제 output
- `y_i`: 정답
- `C`: cost

$\min C(w,b)$ Cost Function의 값이 가장 작아지는 weights와 biases를 찾아야함.

AI가 학습한다 = 매우 큰 함수의 최소값을 찾는 미적분 문제

## Gradient

'어떤 parameter를 어느 방향으로 얼마나 바꾸는 것이 효과적인가' 를 알려줌
내리막이 어떤 방향이고, 얼마나 가파른지를 알려줌.

이 Gradient 계산을 효과적으로 만드는 알고리즘이 Backpropagation.

---

cost 함수가 매끄러운 출력을 갖는 것이 좋다.
그래야 하나씩 내려가면서 지역 최솟값을 찾기 유리하다. 
이런 이유로 인해 뉴런 값을 boolean이 아닌 연속적인 값을 갖는다.

반복적으로 Gradient의 음의 방향으로 함수의 입력값을 이동하는 방식을 Gradient descent(경사 하강법) 라고 한다.cost 함수의 지역 최소값으로 수렴하는 방법

### Gradient 각 숫자의 의미

$\nabla C = \begin{bmatrix} 3\\ 1 \end{bmatrix}$
라고 가정하면, 이를 해석하는 방법은 첫 번째 parameter를 바꾸는 것이 두 번째 parameter보다 현재 cost에 약 3배 더 큰 영향을 준다.

즉 gradient에는 어떤 parameter를 어느 방향으로 얼마나 바꾸는 것이 효과적인가 라는 정보가 담겨있다.

```
[
  0.0001,  # 거의 영향 없
  3.4,  # 꽤 중요
  0.02,  # 영향 적음
  -8.2,  # 매우 중요
  ...
]
```
